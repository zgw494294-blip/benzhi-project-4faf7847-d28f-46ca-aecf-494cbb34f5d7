# 古树迁移作业许可

本项目面向城市树木保护专员、迁移方案编制人员、技术审查人员和现场核验人员，提供一条从迁移档案建立到现场放行的完整业务流程。系统通过树体评估、迁入地条件、方案风险控制、审查问题和开工前核验之间的跨实体规则阻止不合格方案获批，最终冻结获批内容并签发带 SHA-256 内容摘要的不可变作业许可。

## 主要能力

- 建立稳定编号、带版本和状态的古树迁移档案。
- 按编号、树种、迁入地和状态组合检索办理队列，并使用签名游标稳定翻页。
- 校验树体评估与迁入地空间、土壤、排水和运输通道条件，跟踪 180 天有效期并保留重评历史。
- 编制带修订序号的五类迁移措施，核对相邻修订差异，并沿用最近方案后按当前评估重新校验高风险控制。
- 一次提交多项结构化审查问题，规范化去重并汇总结论；逐项保留每轮整改证据、驳回原因和复核决定。
- 从活动方案风险控制生成带版本的冻结清单，严格记录人员、设备、天气、物资及风险项的现场核验和复查。
- 在签发前逐项预检资格，原子冻结两项评估、完整方案、清单和合格核验，签发后独立复验 SHA-256 摘要。
- 使用长度前缀、摘要链事件日志和原子投影快照进行本地持久化与启动恢复。

## 构建与运行

项目要求 Go 1.22 或更高版本。

```bash
go build ./cmd/server
go run ./cmd/server -addr=127.0.0.1:19081 -data-dir=./data
```

服务默认监听 `127.0.0.1:19081`。可通过 `-addr=127.0.0.1:<port>` 修改地址，也可设置 `PORT` 为端口号，此时绑定 `127.0.0.1:<PORT>`。为避免意外暴露，服务拒绝非回环监听地址。

启动后访问 `http://127.0.0.1:19081/` 使用浏览器工作台。健康检查地址为 `GET /api/health`。业务数据默认写入 `./data/events.bin` 和 `./data/snapshot.json`。

档案列表 `GET /api/cases` 支持 `keyword`、可重复或逗号分隔的 `status`、`limit` 和 `cursor` 参数；`status=pending` 表示待整改及待现场核验。修订差异、冻结清单和签发资格分别通过同一档案下的 `/revisions/diff`、`/precheck-checklist` 和 `/permit-eligibility` 查询，所有查询均为只读操作。

## 测试与自检

运行全部单元和集成测试：

```bash
go test ./...
```

通过真实 HTTP 监听执行从建档到许可签发的完整冒烟流程，并在完成后自行退出：

```bash
go run ./cmd/server -selfcheck -addr=127.0.0.1:19081
```

自检使用临时数据目录，不会修改普通运行的业务数据。

## 持久化与并发语义

应用层按 `caseId` 串行处理写命令。每个写请求必须提交当前 `expectedVersion` 和 8 至 128 个安全字符组成的 `idempotencyKey`；过期版本返回 HTTP `409 Conflict`，同一幂等键重试返回首次提交后的结果且不会重复写事件。

事件日志中的每个帧包含 `schemaVersion`、递增序号、前序摘要和校验和，并在确认提交前执行 `Sync`。投影快照通过临时文件、`Sync` 和原子 `Rename` 更新。启动时会拒绝截断尾帧、摘要链断裂、校验和错误或未知 `schemaVersion`，避免静默接受损坏数据。
